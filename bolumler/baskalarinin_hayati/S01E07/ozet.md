# Başkalarının Hayatı S01E07 - özet (sonraki bölümün çevirmenleri için)

- Sarp ile Erim'in kardeş olduğu ortaya çıkıyor (Sarp, Haluk Korhanlı'nın oğlu). Erim çılgına dönüyor, trafik kazası geçiriyor; Jale'nin de bildiğini anlıyor. Fikret Sarp'ı kovuyor, Neslihan'ı eve kapatıyor.
- Sarp'a hocası (Erhan Hoca = "Pak Erhan") Muğla'da klinikte iş teklif ediyor. Neslihan Sarp'a kaçmak isterken Mediha'yla itişip kazayla havuza düşüyor, Fikret kurtarıyor. Neslihan suçu Hülya'ya atıyor, Mediha'yı yalana ortak ediyor; Hülya nezarete giriyor.
- Mediha ağzından "az daha senin de sonunu getirecektim" kaçırıyor. Gülizar duyuyor, Kübra'yı sorguluyor: yangın gecesi evde sadece Mediha varmış. Gülizar ve Hülya yangını Mediha'nın çıkardığından şüpheleniyor. Hülya Mediha'ya "gangster Mediha" ("Mediha si gangster") diyor.
- Salih nezarette Hülya'yı tehdit ediyor, sonra eve dayanıyor; Hülya adamlarına attırıyor. Flashback'ler: Salih küçük Hülya'yı dövüyor ve kilitliyor.
- Korhanlı evine haciz geliyor, Jale evi satıyor, Erim paranın tamamını kumarda kaybediyor. Erim intikam için Sema'ya yaklaşıyor; Sema Özkaran Holding'de çalışıyor. Jale ile Erim Nermin'in evine pansiyoner olarak yerleşiyor; Jale ile Nermin kibar ama iğneli didişiyor.
- Fikret Neslihan'a anlaşma sunuyor: Sarp'la evlenebilir ama İstanbul'da o evde kalacaklar, Hülya'yla savaş bitecek. Sarp kabul ediyor. Fikret ile Hülya barışıyor.
- Düğün: organizasyon ve Sarp'ın nikah şahitliği Hülya'da, Neslihan'ın şahidi İlayda. Hülya Sarp'a "Beni hiç sevmedin mi?" diye soruyor. Nikahta annesinin (Nisan) gelinliği zarar görüyor, Neslihan Hülya'yı suçluyor; Sarp nikahı sürdürüyor.
- Yeni isimler: Halit Bey ("Pak Halit", Sarp'ın eski hastane müdürü), Erhan Hoca, Kübra (evde çalışan), İlayda, Oğulcan (şoför/koruma, yazım emin değil), Sarp'ın soyadı "Yönel" (emin değil, "Yöner" de duyuldu), Firuzan ve Ediz (misafir olabilir, belirsiz).

## Hitaplar
- Gülizar -> Hülya "bacım" = "adikku" (her yerde); kalabalıkta "Nona Hülya". Gülizar -> Mediha lakap "Medişko"; Gülizar -> Fikret lakap "Fiko". Gülizar-Mediha aku/kamu; Gülizar -> Kübra aku/kamu, Kübra -> Gülizar saya.
- Mediha, Orhan, şoför -> Hülya "Nona Hülya", saya. Misafirler, avukat -> "Bu Hülya". Nikah memuru -> "Ibu".
- Sarp ile Hülya bu bölümde aku/kamu. Hülya-Fikret aku/kamu. Sarp -> Fikret "Pak Fikret", saya/Anda; Fikret -> Sarp kamu, "Nak". Sarp -> Neslihan "Sayang". Fikret Neslihan'a kendinden "Papa" diye söz ediyor.
- Erim-Sema başta saya/Anda ("Pak Erim" / "Bu Sema"), yemekten sonra aku/kamu ve isimle. Erim -> Jale "Ma/Mama", Jale -> Erim "Nak". Sema -> Nermin "Mama".
- Nermin <-> Jale: "Bu Jale" / "Bu Nermin", saya/Ibu; alayla "Jale sayang" / "Nermin sayang". Nermin -> Erim "Nak".
- Salih -> Hülya gue/lo ve "kecoak hitam" (küçük harf); Hülya -> Salih kamu. Nermin Hülya'ya Salih için "bapakmu".
- Neslihan -> Mediha "Mediş", aku/kamu. STT'de "Meriç", "Medici", "Betiş" = Mediş. Korumalar -> Neslihan "Nona Neslihan".
- Takma adlar: "kutu bebeğimiz" = "boneka pajangan kita" (Neslihan), "padişahımız" = "sultan kita" (Fikret), "ukala dümbeleği" = "bocah sok tahu".
